# 02: Conditional Phase-1 Opening Response Trees

**Prototype:** Junction-focused draft scouting explorer (`index.html`) mapping side-specific `B1 -> R1/R2 -> B2/B3` conditional response branches and true in-game lane assignments from GRID telemetry.

**Problem Solved:** Season-average pick tables strip away sequence context and get misled by Phase-1 flex picks. Coaches see how opponents conditionally answer specific openers and whether multi-role picks genuinely flex across lanes or bluff one player.

**Traverse:** Open `index.html` to click opener branches, inspect `Flex Bluff Audit`, and verify underlying `GRID Series Logs`.
