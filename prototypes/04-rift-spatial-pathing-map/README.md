# 04: Summoner's Rift Early Pathing & Faelight Map

**Prototype:** Draft-conditioned 2D Summoner's Rift tactical map (`index.html`) plotting `0:00–8:00` GRID `{x, y}` coordinates, jungle clear routes, and Season 2026 `Faelight` vision setups.

**Problem Solved:** Previous League scouting tools lacked spatial playback, forcing analysts to screenshot VOD minimaps manually. Filtering early jungle pathing, Level-1 invades, and river objective formations by drafted lane priority reveals opponent macro tells in seconds.

**Traverse:** Open `index.html`, toggle lane-priority matchups, and step across `Level-1 Invades`, `Jungle Pathing`, and `Faelight Setups`.
