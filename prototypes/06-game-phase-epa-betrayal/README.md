# 06: Phase EPA, Betrayal Index & Prospect Theory

**Prototype:** Empirical sports-analytics engine (`index.html`, powered by `../shared/engine.js`) that partitions League matches into 6 quantized game phases, computes per-phase `EPA`, `Success Rate (SR%)`, and `Leverage Index (LI)`, measures unit/phase `Betrayal Index`, and audits high-leverage in-game & Hard Fearless decisions via Kahneman–Tversky Prospect Theory.

**Problem Solved:** Raw KDA and end-of-game win rates obscure *which* phase or unit created expected win probability versus which phase leaked it. Translating NFL EPA, Success Rate, Betrayal Index, and Prospect Theory exposes empirical decision biases without lecturing players on champion kits.

**Traverse:** Open `index.html`, switch teams and Hard Fearless `G1–G5` states, and inspect `Phase Breakdown`, `Betrayal Index`, and `Prospect Theory Audit`.
